IT102 – Computer Programming

C++ Conditional Statements, Switch, and Loops

C++ if-else switch loops

Activity Overview

Read the instructions carefully before starting your assigned task.

Learning Objectives

At the end of this activity, students should be able to:

  • Apply conditional statements in C++.
  • Use switch statements for menu selection.
  • Use a while loop to repeat a process.
  • Use a for loop for controlled repetition.
  • Perform basic arithmetic calculations in C++.

Activity Setup

This activity has two different parts. Students will be assigned based on their seat or computer.

Student 1
Complete Part 1.
Student 2
Complete Part 2.

Students seated beside each other may receive different tasks.

Alternating Assignment Rule

The instructor may assign the activity alternately per seat or computer. For example: Computer 1 – Student 1, Computer 2 – Student 2, Computer 3 – Student 1, and so on.

Concepts You Will Use

Review these concepts before writing your program.

if-else

Used to make decisions based on conditions.

switch

Used to select an action from several choices.

while loop

Repeats statements while a condition is true.

for loop

Repeats statements using initialization, condition, and update.

Task 1 — Employee Salary Evaluation

Create a C++ program that evaluates an employee's salary based on the employee's years of service.

Program Requirements:
  • Ask for the employee name.
  • Ask for the basic salary.
  • Ask for the years of service.
  • Determine the bonus percentage using conditional statements.
  • Calculate the gross salary.
  • Display the required information.
Bonus Rules
Years of Service Bonus
10 years or more 20%
6–9 years 15%
3–5 years 10%
Below 3 years 5%
Required Input

Your program must ask the user for the following information in this order:

Name:
Salary:
Year of Service:
Example Input
Name: Juan Dela Cruz
Salary: 30000
Year of Service: 7
Important: After receiving the input, your program must determine the employee's bonus based on the Year of Service, then calculate the Gross Salary.
Program Flow
INPUT
Name:
Salary:
Year of Service:
PROCESS

Determine Bonus Rate

Calculate Bonus

Calculate Gross Salary

OUTPUT
Name:
Gross Salary:
Bonus:
Calculation

Bonus Amount = Basic Salary × Bonus Rate

Gross Salary = Basic Salary + Bonus Amount

Suggested Program Flow
1
Declare variables
Store the employee name, salary, years of service, bonus rate, bonus amount, and gross salary.
2
Get the input
Use cin to receive the employee information.
3
Determine the bonus rate
Use if, else if, and else.
4
Calculate
Calculate the bonus amount and gross salary.
5
Display the result
Display the employee name, gross salary, and bonus.

Multiples of 5

Instruction:

Create a C++ program using a while loop that displays the following numbers:

5 10 15 20 25 30
Important Requirement
  • You must use a while loop.
  • Do not manually type every number using separate cout statements.
  • The numbers must increase by 5.
  • The loop must stop after displaying 30.
Think About the Logic

Ask yourself:

  • What should the starting value be?
  • What condition should the while loop check?
  • How much should the variable increase after every repetition?

Student 2

Food Ordering System + Multiples of 5

Task 2 — Food Ordering System

Create a C++ program that allows a customer to select a food item and quantity, then calculates the subtotal.

Food Menu
Choice Food Price
1 Burger ₱80
2 Pizza ₱150
3 Pasta ₱120
4 Chicken ₱100
5 Sandwich ₱70
Ask for:
  • Customer name
  • Food choice
  • Quantity
Use a switch statement

The food choice must be processed using a switch statement.

Each case should assign the correct food price.

Calculation

Subtotal = Price × Quantity

Example: ₱80 × 3 = ₱240

Required Output
Customer: Maria Santos
Order: Burger
Quantity: 3
Price: ₱80
Subtotal: ₱240
Suggested Program Flow
1
Display the menu
Show all five food choices and their prices.
2
Get customer information
Ask for the customer's name, food choice, and quantity.
3
Use switch
Determine the price based on the selected food.
4
Calculate subtotal
Multiply the selected price by the quantity.
5
Display the order
Display all required information.

Multiples of 5

Instruction:

Create a C++ program using a for loop to display the following sequence:

5
10
15
20
25
30
Important Requirement
  • You must use a for loop.
  • The sequence must begin at 5.
  • The value must increase by 5.
  • The final number must be 30.
  • Each number should be displayed using the loop.
Think About the Loop

A for loop normally contains three important parts:

initialization; condition; update

Determine what values should be placed in each part to generate the required sequence.
